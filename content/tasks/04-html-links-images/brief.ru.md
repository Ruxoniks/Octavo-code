[КУРСОР]
У тега бывают **атрибуты** — дополнительные данные внутри открывающего тега:

```html
<a href="https://developer.mozilla.org">Справочник по HTML</a>
```

Здесь `href` — адрес, куда ведёт ссылка. Без него `<a>` останется просто текстом.

---

[ЛОГИКА]
По умолчанию ссылка открывается в той же вкладке: твоя страница исчезает, вместо неё чужой сайт. Если человек ушёл читать справочник, он к тебе уже не вернётся.

Это лечится ещё двумя атрибутами:

```html
<a href="https://developer.mozilla.org" target="_blank" rel="noopener">Справочник</a>
```

`target="_blank"` просит браузер открыть соседнюю вкладку. `rel="noopener"` пишут рядом всегда: без него открытая страница получает доступ к твоей вкладке и может её подменить.

---

[КУРСОР]
Картинка устроена похоже, но закрывающего тега у неё нет:

```html
<img src="cursor.svg" alt="Курсор мыши крупным планом" />
```

`src` — путь к файлу, `alt` — описание словами. `alt` читают программы для незрячих и поисковики, а ещё он показывается, если картинка не загрузилась. Пустой `alt` у смысловой картинки — распространённая ошибка.

---

[ЛОГИКА]
Списки ты уже видел, но напомню главное: сам `<ol>` — только контейнер. Текст в него не пишут, каждый пункт — отдельный `<li>` внутри:

```html
<ol>
  <li>Первый пункт</li>
  <li>Второй пункт</li>
</ol>
```

`<ol>` от `<ul>` отличается одним: браузер сам расставляет номера, и они меняются, если ты вставишь пункт в середину.

---

[ЛОГИКА]
## Что нужно сделать

1. Добавь ссылку `<a>` на любой сайт (адрес должен начинаться с `https://`), осмысленный текст внутри — не «тут» и не «ссылка» — и открой её в новой вкладке.
2. Вставь картинку `<img>` — файл `cursor.svg` уже лежит рядом — и напиши ей `alt` хотя бы из трёх слов.
3. Собери нумерованный список `<ol>` из трёх пунктов: что ты уже умеешь.

Ссылку в превью можно нажать — она откроется по-настоящему.
