[КУРСОР]
HTML говорит, **что** на странице. CSS — **как оно выглядит**.

Правило состоит из селектора и набора свойств:

```css
h1 {
  color: #1a7f37;
}
```

Селектор отвечает на вопрос «к каким элементам это применить»:

- `h1` — ко всем тегам `<h1>`;
- `.tag` — ко всем элементам с `class="tag"` (точка);
- `#hero` — к элементу с `id="hero"` (решётка, и такой элемент на странице один).

Разметка в `index.html` уже готова — работаем в `style.css`. Открыть и поправить HTML тоже можно, но проверка смотрит на стили.

---

[ЛОГИКА]
## Что нужно сделать

1. Покрась заголовок `<h1>` в любой цвет, кроме чёрного.
2. Сделай элементам с классом `tag` заметный фон.
3. Задай блоку `#hero` свой фон — так, чтобы он отличался от фона страницы.

Цвет можно писать по-разному: `#1a7f37`, `rgb(26, 127, 55)` или словом вроде `teal`. Браузер поймёт любой вариант.
