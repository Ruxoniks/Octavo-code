[КУРСОР]
Последний шаг: сделать так, чтобы страницу можно было открыть по ссылке — с любого телефона, без твоего ноутбука.

---

[ЛОГИКА]
GitHub Pages берёт файлы прямо из репозитория и раздаёт их как обычный сайт. Никакого сервера настраивать не нужно.

Как включить, один раз:

1. Открой репозиторий на GitHub → **Settings** → в левом меню **Pages**.
2. В блоке *Build and deployment* выбери **Deploy from a branch**.
3. Ветка — `main`, папка — `/ (root)`. Нажми **Save**.
4. Подожди минуту и обнови страницу настроек: наверху появится ссылка вида `https://имя.github.io/репозиторий/`.

Требование одно: в корне репозитория должен лежать `index.html` — тот самый файл, о котором говорили в задании про структуру проекта.

---

[ЛОГИКА]
Дальше сайт обновляется теми же командами, что ты уже знаешь:

```
git add .
git commit -m "Что изменил"
git push
```

Через несколько секунд после пуша страница в интернете становится новой. Это и есть деплой: не «выложить файлы по FTP», а **отправить коммит**.

Проделай это в симуляторе: измени README (`echo "Опубликован на GitHub Pages" >> README.md`), закоммить и запушь.

---

[ПАМЯТЬ]
А если не Pages, а обычный сервер? Всё то же самое, только руками:

```
ssh user@адрес-сервера        зайти на сервер
cd /var/www/site              перейти в папку сайта
git pull                      забрать свежие коммиты
```

Тот же git, тот же репозиторий — просто копию забирает сервер, а не GitHub. Понимаешь одну схему — понимаешь обе.

---

[КУРСОР]
Когда страница откроется — вставь её адрес в поле внизу. Это твой первый сайт в интернете, и ссылку уже можно кому-нибудь отправить.
