Базовый набор на каждый день:

```
pwd                 где я сейчас
ls                  что лежит рядом
cd site             зайти в папку site
cd ..               выйти на уровень вверх
mkdir styles        создать папку
mkdir -p a/b/c      создать цепочку папок разом
touch index.html    создать пустой файл
```

[КУРСОР]
Вторая половина задания — настоящая. Установи Node.js с [nodejs.org](https://nodejs.org) (бери версию LTS), открой **свой** терминал и выполни `node -v` и `npm -v`.

Вывод вставь в поля внизу. Node пригодится дальше: на нём работают сборщики, локальные серверы и почти весь современный инструментарий.

---

[ПАМЯТЬ]
Как открыть терминал у себя:

- **Windows** — «Терминал» или PowerShell из меню «Пуск»;
- **macOS** — Terminal через Spotlight (Cmd+Space);
- **Linux** — ты и так знаешь.

Если `node -v` отвечает «command not found» — закрой терминал и открой заново: путь к программе подхватывается при запуске.
