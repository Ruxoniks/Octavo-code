[ТЕРМИНАЛ]
Две вещи, которых ты ещё не встречал.

**`mv`** — переместить или переименовать: `mv style.css styles/` кладёт файл в папку, `mv main.html index.html` переименовывает.

**`.gitignore`** — список того, что git не должен видеть. Обычный текстовый файл, одна строка — одно правило:

```
node_modules/
```

Остальное ты уже умеешь: `ls`, `cd`, `mkdir`, `rm -r`, `git init`, `git add`, `git commit`.

---

[ПАМЯТЬ]
Две ловушки.

`node_modules` **нельзя удалять** — без него проект не запустится. Но и в репозиторий он не попадает: сотни мегабайт чужого кода, который целиком восстанавливается одной командой `npm install`. Отсюда и `.gitignore`.

И порядок важен: если сделать `git add .` до того, как появился `.gitignore`, git уже возьмёт `node_modules` в работу.
