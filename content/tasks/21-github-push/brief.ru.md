[КУРСОР]
Коммиты лежат у тебя на диске. Диск может умереть, ноутбук — потеряться, а работу неплохо бы кому-то показать. Пора вывести проект наружу.

---

[ЛОГИКА]
GitHub — это место, где живёт копия твоего репозитория. Связь настраивается один раз тремя командами:

```
git remote add origin https://github.com/имя/репозиторий.git
git branch -M main
git push -u origin main
```

Что здесь что:

- `remote add origin <адрес>` — «запомни, что удалённая копия живёт вот тут». `origin` — просто общепринятое имя для основного адреса;
- `branch -M main` — переименовать текущую ветку в `main`, потому что GitHub ждёт именно её;
- `push -u origin main` — отправить коммиты. Флаг `-u` запоминает связь, и дальше хватит просто `git push`.

---

[ЛОГИКА]
Сначала сделай это у себя:

1. Зарегистрируйся на [github.com](https://github.com), если ещё нет аккаунта.
2. Нажми **New repository**, дай имя (например, `site`), **не** ставь галочку «Add a README» — репозиторий должен быть пустым.
3. Скопируй адрес со страницы — он вида `https://github.com/имя/site.git`.

Потом повтори три команды в симуляторе слева и вставь ссылку на свой репозиторий в поле внизу.

---

[ПАМЯТЬ]
Порядок важен: пуш без `remote` git отклонит, потому что не знает адреса. Попробуй `git push` до `remote add` — увидишь ту самую ошибку, которую видят все в первый раз.

При настоящем пуше GitHub спросит логин. Пароль от аккаунта там не подойдёт: нужен токен из настроек (Settings → Developer settings → Personal access tokens) — так безопаснее.
