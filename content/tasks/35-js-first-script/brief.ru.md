[КУРСОР]
HTML — структура, CSS — внешний вид, JavaScript — **поведение**. Скрипт умеет находить элементы на странице и реагировать на действия.

Три шага, которые лежат в основе почти любого интерфейса:

```js
const button = document.querySelector('#toggle');   // 1. найти элемент

button.addEventListener('click', function () {      // 2. подписаться на событие
  button.textContent = 'Нажали!';                   // 3. что-то изменить
});
```

---

[ЛОГИКА]
## Что нужно сделать

В файле `app.js`:

1. Найди кнопку `#toggle` и абзац `#status`.
2. По клику переключай текст статуса: было «Закрыто» — стало «Открыто», и наоборот.
3. Текст должен переключаться **каждый раз**, а не только при первом нажатии.

Проверка сама нажмёт на кнопку несколько раз и посмотрит, что получилось. Всё, что попадёт в `console.log`, видно в консоли под превью — это твой главный инструмент отладки.
