[КУРСОР]
Ступеньки в разметке уже есть — все пять. Но координат у них нет, поэтому они свалились в кучу в левом верхнем углу, а я стою внизу и жду.

---

[ЛОГИКА]
Позиционирование работает так:

```css
.ladder {
  position: relative; /* точка отсчёта */
  height: 420px;
}

.step {
  position: absolute; /* координаты считаются от .ladder */
}

.step--1 {
  bottom: 20px;
  left: 20px;
}
```

`bottom` — сколько пикселей от низа контейнера, `left` — от левого края.

---

[ЛОГИКА]
Расставь пять ступенек так, чтобы курсор смог подняться:

- каждая следующая **выше** предыдущей;
- подъём между соседними — **не больше 90px**;
- по горизонтали разрыв — **не больше 140px**;
- самая верхняя — где-то у отметки 300px, там кнопка.

---

[ПАМЯТЬ]
Ширина ступеньки 90px, высота контейнера 420px. Прикинь на бумаге, влезет ли твой план, прежде чем писать — это дешевле, чем подбирать числа наугад.
