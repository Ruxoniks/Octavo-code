[КУРСОР]
Посмотри на `style.css`: цвет `#1a7f37` встречается в нём несколько раз. Стоит поменять фирменный цвет — и придётся искать все места. Одно пропустишь — получишь страницу двух оттенков.

В CSS есть переменные:

```css
:root {
  --brand: #1a7f37;
}

h1 {
  color: var(--brand);
}
```

`:root` — это корень документа, то есть переменная становится доступна везде. Именно так устроена и сама эта игра: тёмная и светлая темы — это два набора значений одних и тех же переменных.

---

[ЛОГИКА]
## Что нужно сделать

1. Объяви в `:root` переменные `--brand` и `--surface`.
2. Замени все повторяющиеся цвета на `var(--brand)` и `var(--surface)`.
3. Убедись, что вид страницы не изменился — рефакторинг не должен ничего ломать.

Проверка сравнивает **вычисленные** цвета: заголовок и кнопка должны получить ровно тот цвет, который лежит в переменной.
