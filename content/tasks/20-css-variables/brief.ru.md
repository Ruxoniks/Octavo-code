[КУРСОР]
Посмотри на `style.css`: цвет `#b3714a` встречается в нём несколько раз. Стоит поменять фирменный цвет — и придётся искать все места. Одно пропустишь — получишь страницу двух оттенков.

В CSS есть переменные:

```css
:root {
  --brand: #b3714a;
}

h1 {
  color: var(--brand);
}
```

`:root` — это корень документа, то есть переменная становится доступна везде. Именно так устроена и сама эта игра: все её цвета лежат в одном файле переменных, и поменять оформление целиком можно, не тронув ни один компонент.

---

[ЛОГИКА]
## Что нужно сделать

1. Объяви в `:root` переменные `--brand` и `--surface`.
2. Замени все повторяющиеся цвета на `var(--brand)` и `var(--surface)`.
3. Убедись, что вид страницы не изменился — рефакторинг не должен ничего ломать.

Проверка сравнивает **вычисленные** цвета: заголовок и кнопка должны получить ровно тот цвет, который лежит в переменной.
